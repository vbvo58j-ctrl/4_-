# المرحلة الرابعة: المصافحة المتبادلة عبر Wi‑Fi Aware

## ما أضيف
- الإعلان الأولي `BLUSAB2` لا يحمل اسم نظام Android ولا صورة أو اسم مستخدم غير موثوق؛ يحمل معرّف Blousab مختصراً وبصمة مفتاح Ed25519 فقط.
- عند اكتشاف إعلان Blousab يبدأ تبادل رسائل داخل جلسة Wi‑Fi Aware، ولا يتم فتح مسار بيانات أو اتصال محادثة بسبب الاكتشاف وحده.
- `BLUSAB_WIFI_HELLO|1` يبادل معرّف Blousab وتحدياً عشوائياً جديداً بطول 256 بت لكل طرف.
- `BLUSAB_WIFI_ID|1` يبادل المفتاح العام والاسم المختصر وتوقيع Ed25519 لهوية الطرف، برسالة قصيرة مناسبة لقناة الاكتشاف.
- `BLUSAB_WIFI_PROOF|1` يحمل توقيعاً على transcript موحّد يتضمن معرّفي الطرفين والتحديين بالترتيب القانوني نفسه.
- لا يصدر `wifiVerified` إلا بعد التحقق من توقيع الهوية وإثبات التحدي المتبادل، مع رفض إعادة استخدام التحدي أو اختلاف المفتاح لنفس معرّف المستخدم.
- طلب فتح قناة بيانات Wi‑Fi Aware يرفض محلياً ومن الطرف المستقبل إذا لم تكن المصافحة قد نجحت.
- سجل المستخدمين الموحد يقبل حدث Wi‑Fi الموثق ويطابق المفتاح العام مع Bluetooth عند توفر المسارين، ويمنع دمج هويتين لمجرد تطابق userId.
- تظهر الهوية الموثقة عبر Wi‑Fi في قائمة مستخدمي بلوساب، لكن لا نعرضها كقناة رسائل جاهزة بعد؛ تكامل خط إرسال الرسائل والملفات مع socket الخاص بـ Wi‑Fi Aware هو خطوة لاحقة.

## حدود لم يتم ادعاء إنجازها
- لم يتم بعد ربط إرسال الرسائل والملفات في Flutter بقناة Wi‑Fi Aware؛ المسار الحالي للرسائل يعتمد على Bluetooth أو LocalNetworkService، ولا يجوز وصف Wi‑Fi Aware بأنه ناقل رسائل مكتمل.
- صورة الملف الشخصي الكاملة لا تُرسل في رسائل المصافحة القصيرة؛ تُعرض صورة مخزنة سابقاً إن وجدت، ويحتاج نقل الصورة/الملف الشخصي إلى مزامنة لاحقة بعد المصادقة.
- لا يوجد اختبار فعلي بين هاتفين أو بناء APK في هذه البيئة.
- المصادقة الذاتية تثبت حيازة المفتاح فقط؛ التحقق من أن المفتاح يعود للشخص المقصود يتطلب مقارنة بصمة/QR خارج القناة عند أول تواصل.

## بروتوكول المصافحة
1. كلا الطرفين يرسلان HELLO يحتوي nonce عشوائياً مستقلاً.
2. بعد استقبال HELLO، يرسل كل طرف مفتاحه العام واسمه مع توقيع هوية ذاتي.
3. يتحقق الطرف الآخر من التوقيع باستخدام المفتاح المعلن.
4. يوقع كل طرف transcript الذي يضم nonce الطرفين ومعرّفيهما.
5. لا تُعتمد الهوية إلا بعد إرسال الإثبات المحلي والتحقق من إثبات الطرف المقابل.

## تحقق الحزمة
تم التحقق من سلامة أرشيف ZIP بعد ضغط المشروع. لم تتوفر أوامر Flutter/Dart أو Android SDK لتنفيذ analyze/build، ولم يتم إجراء اختبار أجهزة حقيقي.
