# المرحلة الثانية – الخطوة السادسة: تبادل معلومات المسارات

## ما أضيف
- خدمة `MeshRouteDirectory` لتخزين تلميحات مسارات قصيرة العمر ومحدودة العدد.
- تبادل إعلانات المسارات عند قيام قناة Wi-Fi Aware مباشرة بين مستخدمين.
- قبول الإعلان فقط عندما يطابق `senderId` هوية النظير المرتبط، مع حدود لحجم القائمة وعدد القفزات.
- انتهاء صلاحية التلميحات بعد ثلاث دقائق، ومنع إعادة إعلان المسارات عبر نفس النظير (split horizon).
- إدخال المسار المتعلم في ترتيب اختيار الوسيط عند إرسال حزمة ذات مستلم محدد.

## حدود مهمة
- هذه تلميحات توجيه وليست إثبات هوية أو ضمان وصول؛ يجب أن تبقى المصادقة والتشفير على مستوى بروتوكول الرسائل.
- التبادل الحالي مربوط بأحداث Wi-Fi Aware داخل شاشة المحادثة؛ لم يتم بعد تعميمه على كل خدمات النقل أو Bluetooth.
- لا توجد حتى الآن آلية سحب فورية للمسارات عند انقطاع وسيط؛ الانتهاء الزمني يعالج التلميحات القديمة تدريجيًا.
- لم يُشغّل `flutter analyze` أو اختبارات الأجهزة في هذه البيئة لعدم توفر Flutter/Dart، لذا يلزم التحقق في بيئة البناء.
