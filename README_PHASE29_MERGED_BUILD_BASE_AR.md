# بلوساب — المرحلة 29 المدمجة مع إصلاحات بناء المرحلة 28

تم اعتماد ملفات Android الخاصة بالمرحلة 29 لنقل ملكية مفاتيح وتشفير حزم Wi-Fi Aware AES-256-GCM إلى BlousabBackgroundService، مع إبقاء ملفات Dart من حزمة إصلاح المرحلة 28 حتى لا تضيع إصلاحات أخطاء Dart السابقة.

## ما تم دمجه
- نقل مفاتيح جلسة Wi-Fi Aware وعدادات AES-GCM والتحقق من nonce وAAD إلى الخدمة الخلفية.
- MainActivity تستدعي الخدمة لتشفير الحزم وفكها ولا تحتفظ بخريطة مفاتيح الحزم.
- الاحتفاظ بملفات lib/ من نسخة Build Fixes للمرحلة 28، بما فيها إصلاح الأقواس وتدفق Socket وتحويل Uint8List.
- إضافة README المرحلة 29 الأصلي.

## ما لم يكتمل في هذه المرحلة
لا تزال ملكية NetworkCallback وNDP ومقابس TCP وخادم الاستقبال ومضخة القراءة/الكتابة وإعادة الاتصال في MainActivity. نقلها هو نطاق المرحلة التالية.

## التحقق
- تم التحقق من سلامة أرشيف ZIP.
- تم فحص وجود نقاط استدعاء تثبيت/إزالة المفاتيح والتشفير وفك التشفير بين MainActivity والخدمة.
- لم يتم تشغيل Flutter analyze أو Gradle build أو اختبار جهازين؛ لذلك لا يُدّعى نجاح APK.
