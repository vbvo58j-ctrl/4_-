# بلوساب — نسخة تجربة المرحلة 29 بالهوية الجديدة

- تحديث أيقونة Android إلى الشعار النيون المعتمد بجميع كثافات العرض.
- اعتماد خلفية داكنة افتراضيًا ولوحة ألوان زرقاء/بنفسجية.
- تحديث رأس التطبيق وإظهار مؤشري Bluetooth وWi‑Fi بجانب الإشعارات.
- تعطيل قفل التطبيق القديم وإزالة مدخله من الإعدادات.
- الاحتفاظ بكود وخدمات المرحلة 29 المدمجة كما هي.

## التحقق
تم إنشاء وفحص أرشيف ZIP فقط. لم يتم تشغيل Flutter analyze أو Gradle build أو اختبار اتصال بين هاتفين؛ لا تعتبر هذه الحزمة APK جاهزًا قبل بنائها على بيئة Flutter/Android SDK.
