# دمج واجهة توثيق الهوية عبر QR

- إضافة شاشة تعرض رمز هوية بلوساب وبصمتها، وتمسح رمز الطرف الآخر.
- ربط الشاشة بصفحة الإعدادات.
- إضافة اعتماديات `qr_flutter` و`mobile_scanner`.
- المسح والتحليل لا يثبتان المفتاح تلقائيًا؛ التثبيت لا يحدث إلا بعد تفعيل تأكيد المستخدم بأنه قارن البصمتين عبر قناة مستقلة.
- رفض محاولة توثيق معرّف الهاتف المحلي باعتباره مستخدمًا آخر.
- تستخدم الشاشة `trustPeerKeyAfterFingerprintCheck`، التي ترفض استبدال مفتاح مثبت سابقًا.

ملاحظة: هذه خطوة واجهة التوثيق الصريح. لا تعني وحدها أن مصافحة Bluetooth أصبحت مشفرة أو موثقة؛ لا يزال ربط المصافحة الأصلية مطلوبًا.
